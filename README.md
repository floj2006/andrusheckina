# Анна Андрюшечкина — сайт ведущей

Откройте index.html двойным щелчком. Для локального сервера: npm start, затем http://localhost:4173. Устанавливать зависимости не нужно. Проверка JavaScript: npm run check.

Сайт адаптирован под телефон, планшет и компьютер. Фотографии берутся из исходной папки photo anna; оригиналы сохранены. Шрифт Manrope загружается из Google Fonts, при отсутствии сети используется Arial.

## Публикация на Vercel из GitHub

Импортируйте репозиторий в Vercel и нажмите Deploy. Конфигурация уже задана в vercel.json: Framework — Other, команда сборки — npm run build, папка результата — dist. Переменные окружения не нужны.

Сборка копирует только страницу, стили, JavaScript, значок, лицензию и используемые фотографии. Документация, локальный сервер, проверочные снимки и архивы в публичную версию не попадают. Локальная проверка сборки: npm run check, затем npm run build.

Текущая интеграция VK копирует текст и открывает диалог. Автоматическое заполнение поля сообщения на стороне VK не подтверждено и не заявляется как работающая функция.

## Воронка продаж

1. Привлечение: ссылка в соцсетях, QR-код на визитке, рекомендации. Первый экран знакомит с Анной через настоящий портрет и короткое обещание атмосферы.
2. Узнавание своего запроса: семь групп событий, включая концерты и другие частные и корпоративные поводы. Кнопка внутри формата заранее выбирает его в форме.
3. Доверие: личный рассказ Анны, три года в профессии, собственные проекты «Для своих» и «Семейные каникулы», принципы общения с гостями и подготовки. Без вымышленных отзывов, наград и статистики.
4. Снятие сомнений: этапы работы и ответы о стоимости, программе, сроках и оборудовании.
5. Конверсия: выбор формата, необязательной даты, числа гостей, пожеланий, имени и контакта. Второй шаг показывает редактируемое сообщение. Кнопка копирует текст и открывает ссылку прямого диалога https://vk.me/anna_vedu_chel. Посетитель вставляет текст и отправляет его самостоятельно. VK может запросить вход или предложить открыть приложение. Можно вернуться к деталям без потери значений. Резервный путь — звонок или отдельное копирование текста. При недоступности буфера обмена текст выделяется для ручного копирования.
6. После обращения: уточнить доступность даты и задачу; провести знакомство; согласовать программу, стоимость и условия; подтвердить бронирование; после события запросить обратную связь. Эти этапы выполняются Анной, сайт их не автоматизирует.

## Перед публикацией

- Согласовать с Анной тексты о её подходе к работе.
- Проверить доступность личных сообщений на странице Анны во ВКонтакте: https://vk.ru/anna_vedu_chel.
- География и факты в тексте взяты из брифа: Челябинск, работа по России, три года в профессии.
- При наличии добавить настоящие отзывы и видео с разрешением на публикацию.
- Canonical и Open Graph настроены на https://andrusheckina.vercel.app/. При смене домена обновить их в index.html.

Форма не хранит и не отправляет данные на сервер сайта. Необязательные имя и контакт включаются в текст сообщения вместе с типом события, датой, количеством гостей и пожеланиями. Сообщение посетитель отправляет самостоятельно во ВКонтакте. На втором шаге явно указано, что текст ещё не отправлен: получение заявки нельзя подтвердить со стороны статического сайта. Подтверждение отправки — сообщение в переписке VK. Для автоматической доставки и подтверждения на сайте потребуется отдельная серверная интеграция с каналом получения заявок Анны. Аналитика и CRM не подключены.

В галерее размещены семь настоящих фотографий, предоставленных пользователем. Веб-копии находятся в photo anna/gallery; полученные исходники сохранены локально в preview/gallery-originals и не входят в сборку. Карусель плавно движется по кругу и останавливается при наведении, касании, фокусе, открытом просмотре и вне экрана. Кнопок под каруселью нет; при уменьшении движения автоматическое вращение отключено и доступна ручная прокрутка. Крупный просмотр поддерживает стрелки, Escape и свайпы; без JavaScript остаются горизонтальная лента и ссылки на фотографии.

Ручные правки сообщения сохраняются в памяти страницы при возврате к деталям. Если детали изменились, посетитель выбирает «Обновить по форме» или «Оставить мой текст». До выбора копирование и переход в VK недоступны. Контакты и черновик не записываются в браузерное хранилище; перезагрузка начинает новую сессию.

## Файлы

- index.html — содержание и структура.
- styles.css — оформление, адаптивность, анимации и режим уменьшенного движения.
- app.js — меню, выбор формата, два шага формы, копирование сообщения и ссылка VK.
- gallery.css и gallery.js — автоматическая кольцевая карусель и доступный полноэкранный просмотр.
- server.cjs — локальный сервер предпросмотра.
- photo anna/ — исходные фотографии.
- ICON-LICENSES.txt — источники и лицензии значков. Интерфейсные SVG — Lucide, фирменный VK — Simple Icons. SVG встроены в страницу и не зависят от внешней загрузки.

Для обычного статического хостинга достаточно index.html, styles.css, app.js, gallery.css, gallery.js, favicon.svg и папки photo anna. Сервер Node для опубликованной версии не обязателен.
